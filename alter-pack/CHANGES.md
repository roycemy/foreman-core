# Alter design pack: changes

**Brand**
- Name Black Box → Alter. Wordmark: lowercase bold Geist "alter".
- Logo H1, island tray: an iso tray with a vermilion dot that shows only while something waits. The pack includes the mark, idle mark, dark mark, card mark (#ECE9E2), lockups, app icons light/dark (512/180) and a favicon in a firm cut (heavier stroke, bigger dot) so the dot holds at 16px.
- Usage rules: `screens/brand.html` and `shots/16-brand-*`.

**Screens**
- Every vNext screen is rebranded: top bar, card, receipt footer, phone, favicon and titles.
- Round L: the label "Most one purchase can be" is now "Max per purchase". The wordmark is lowercase.
- Landing:
  - New mark and lowercase wordmark.
  - Primary buttons are rounded ink instead of square vermilion.
  - The hero shows the vNext floor with island B; the old red island and robot figures are gone.
  - The italic red headline is now upright.
  - "SYNTHETIC ONLY. No money moves." is now "Sandbox. No real money moves."
- Tokens are consolidated in `tokens.css`.
